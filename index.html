Calculadora de Cálculo Planimétrico

Página estática em HTML, CSS e JavaScript para GitHub Pages. Ela segue a convenção da aula: azimute a partir do Norte no sentido horário, projeções relativas por X = d · sen(Az) e Y = d · cos(Az), fechamento angular, cálculo dos azimutes, fechamento linear, correções proporcionais e coordenadas absolutas.

Entradas

Defina o número de vértices e preencha os dados. Os campos são gerados automaticamente.

Os rótulos devem ter a mesma quantidade de vértices. Se ficar vazio, a página gera automaticamente.
Formatos aceitos para ângulos e azimutes: graus decimais ou G M S.
Exemplos válidos: 76°33', 76 33 45, 76.5625.
Convenção adotada na página: Azᵢ₊₁ = Azᵢ + AHcorr - 180°, com normalização para 0°–360°.
